# Code of Conduct

Way More Fish is intended to be a useful, welcoming, and credible open-source community project.

## Expected behavior

Participants should:

- Be respectful and constructive.
- Focus criticism on ideas, code, data, or methods rather than people.
- Be especially careful with fishing-location coordinates and environmental data; corrections should be supported by reliable evidence whenever possible.
- Clearly distinguish personal observations from official measurements, forecasts, or verified geographic information.
- Avoid harassment, personal attacks, discrimination, threats, or deliberately disruptive behavior.
- Respect privacy and do not publish another person's private information without permission.

## Project standards

Maintainers may edit, reject, or remove contributions that are inaccurate, unsafe, abusive, misleading, unrelated to the project, or inconsistent with these standards.

Good-faith disagreement is welcome. The goal is to improve the quality and usefulness of the project.

## Reporting problems

If you encounter conduct that violates these standards, report it privately to the project maintainer rather than escalating the dispute publicly.

## Scope

This Code of Conduct applies to project repositories, issues, pull requests, discussions, and other official Way More Fish community spaces.
