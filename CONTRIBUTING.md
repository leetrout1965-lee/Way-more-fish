# Contributing to Way More Fish

Thanks for helping improve Way More Fish.

The project is focused on useful, transparent information for Louisiana coastal anglers. Contributions are welcome from developers, anglers, researchers, and community members.

## Good contributions include

- correcting or verifying fishing-location coordinates
- improving tide, weather, wind, pressure, or water-condition data
- improving data-source transparency
- fixing bugs
- improving mobile usability
- documenting how scoring or ranking works
- adding tests
- improving accessibility
- adding reliable Louisiana coastal fishing information

## Location and data standards

Please do not add a fishing location based only on an approximate guess.

When possible, include the source used to verify:

- location name
- latitude and longitude
- environmental observation
- forecast or measured value
- fishing report date and context

Community fishing reports should be clearly labeled as community observations rather than official data.

## Before submitting code

1. Keep changes focused.
2. Test the affected feature.
3. Explain what changed and why.
4. Note any new data source or external dependency.
5. Do not commit passwords, API keys, access tokens, or other secrets.

## Pull requests

A useful pull request should include:

- a short description of the problem
- what was changed
- how the change was tested
- screenshots when a user-interface change is involved
- any data-source or coordinate-verification notes that matter

## Project direction

Way More Fish is currently operated as a non-commercial Louisiana coastal fishing/community-data project.

The software itself is available under the MIT License. Contributions accepted into the repository will be distributed under that same license unless explicitly stated otherwise.
